Modern inbox providers (Gmail, Microsoft 365, Yahoo) immediately reject emails dispatched from servers that fail **Forward-Confirmed Reverse DNS (FCrDNS)**. This guide walks you through establishing perfect bidirectional hostname-to-IP symmetry.

```text
Forward Resolution:  mail.yourdomain.com  ──────(DNS A Record)──────►  198.51.100.1
Reverse Resolution:  198.51.100.1        ──────(rDNS / PTR)────────►  mail.yourdomain.com
```

---

## 1. Configure DNS: Host 'A' Records

Add the `A` records pointing your mail server, web dashboard, and docs platform to your VPS public IPv4:

| Type | Name / Host | IPv4 Address | Proxy Status | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `A` | `mail` | `<YOUR_VPS_IP>` | **DNS Only / Unproxied** | SMTP EHLO & Reverse DNS (PTR) for 10/10 deliverability |
| `A` | `emitmail` | `<YOUR_VPS_IP>` | **DNS Only** or **Proxied** | EmitMail Web Dashboard & REST API (`https://emitmail...`) |
| `A` | `emitdocs` | `<YOUR_VPS_IP>` | **DNS Only** or **Proxied** | EmitDocs Documentation Platform (`https://emitdocs...`) |

<Callout type="warn" title="DNS Only for Mail Server Hostname">
If using Cloudflare or a CDN proxy service, do NOT enable the proxy (e.g. Cloudflare Orange Cloud) for `mail.yourdomain.com`. Proxies only handle HTTP/HTTPS web traffic (ports 80/443) and will drop raw SMTP Port 25 connections. Keep `mail` **DNS Only / Grey Cloud**. `emitmail` and `emitdocs` can safely be proxied or unproxied.
</Callout>

---

## 2. VPS Provider Networking Panel: Reverse DNS (PTR)

Log in to your hosting provider's management console (DigitalOcean, Hetzner, Vultr, Linode, AWS) and locate the **Networking / IPv4** tab:

<Steps>
  <Step>
    Find your primary public IPv4 address.
  </Step>
  <Step>
    Click **Edit PTR / Reverse DNS**.
  </Step>
  <Step>
    Set the PTR value to your exact mail server hostname:
    ```text
    mail.yourdomain.com
    ```
  </Step>
</Steps>

---

## 3. Verifying FCrDNS Verification

From your local machine or VPS terminal, run `dig`:

```bash
# 1. Test Forward A Resolution
dig +short A mail.yourdomain.com
# Output should return: <YOUR_VPS_IP>

# 2. Test Reverse PTR Resolution
dig +short -x <YOUR_VPS_IP>
# Output should return: mail.yourdomain.com.
```

When both outputs match, your mail server satisfies strict anti-spoofing requirements.

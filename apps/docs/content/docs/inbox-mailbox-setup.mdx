EmitMail can receive mail for configured domains, display messages in the dashboard inbox, and send inbound message events to subscribed webhooks.

---

## 1. Configure DNS: Inbound Root MX Record

To receive mail for a domain, publish an MX record that points to a mail hostname resolving to your server. Use the hostname configured for your EmitMail deployment. The example below is illustrative; confirm the value with your administrator:

| Type | Host / Name | Mail Server Target | Priority | Proxy Status |
| :--- | :--- | :--- | :--- | :--- |
| `MX` | `@` (root domain) | `mail.yourdomain.com` | `10` | DNS only; do not use an HTTP proxy |

<Callout type="warn" title="Single MX Routing">
Changing MX records affects mail delivery for the whole hostname. Do not replace existing Google Workspace, Microsoft 365, or other provider MX records unless you intend to move that domain's inbound mail. Use a dedicated subdomain if appropriate, and check your existing provider's setup before changing DNS.
</Callout>

---

## 2. Creating Mailboxes in Dashboard

<Steps>
  <Step>
    ### Configure and verify the domain
    Add and verify the domain in **Dashboard -> Domains**. For inbound delivery, confirm its MX record points to the configured mail host and that the host resolves to your server IP. The inbound mailbox setup checks the domain's MX configuration.
  </Step>

  <Step>
    ### Create an Inbound Mailbox Alias
    In **Dashboard -> Inbox**, create a mailbox on the configured domain:
    - **Exact Alias:** Enter `support` to receive mail at `support@yourdomain.com`.
    - **Team Alias:** Enter `hello`, `contact`, or `billing`.
    - **Catch-All Mailbox:** Enter `*` to accept mail for otherwise unassigned addresses. Use this carefully because it can receive unwanted mail.
  </Step>

  <Step>
    ### Send a Test Email
    From an external email client (such as your personal Gmail or Outlook account), send an email to `support@yourdomain.com`.
  </Step>

  <Step>
    ### Real-Time Ingestion & Thread Replies
    The incoming message arrives at your VPS on port 25, is validated by EmitMail's recipient gate (`onRcptTo`), parsed via `mailparser`, and appears inside `/inbox` in real time. Click the email thread to read rich HTML, view attachments, and reply directly.
  </Step>
</Steps>

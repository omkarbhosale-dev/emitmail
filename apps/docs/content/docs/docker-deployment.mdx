## 1. Quickstart Commands

<Steps>
  <Step>
    ### Clone the Repository
    ```bash
    git clone https://github.com/omkarbhosale-dev/emitmail.git
    cd emitmail
    ```
  </Step>

  <Step>
    ### Create and Populate Environment File
    ```bash
    cp .env.example .env
    ```
  </Step>

  <Step>
    ### Configure Environment Variables
    Open `.env` in your preferred editor (`nano .env`) and update the key host settings:
    ```bash
    # Core Server Ports
    PORT=4000
    API_PORT=4000
    DASHBOARD_PORT=3000
    DOCS_PORT=3001

    # Security Keys
    # Must be at least 32 characters
    JWT_SECRET=emitmail_super_secret_jwt_key_change_in_prod_2026
    # 64-character hex string (32 bytes) for AES-256-GCM DKIM encryption
    ENCRYPTION_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef

    # Mail Server Network Configuration
    SMTP_EHLO_HOSTNAME=mail.yourdomain.com
    SENDING_SERVER_IP=198.51.100.1
    RETURN_PATH_SUBDOMAIN=send
    MAIL_SERVER_HOSTNAME=mail.yourdomain.com
    SPF_INCLUDE_DOMAIN=_spf.yourdomain.com
    VPS_PUBLIC_IPV4=198.51.100.1

    # Inbound SMTP Receiver Engine
    INBOUND_SMTP_ENABLED=true
    INBOUND_SMTP_PORT=2525
    INBOUND_SMTP_HOST=0.0.0.0
    INBOUND_MAX_BYTES=26214400
    ```
  </Step>

  <Step>
    ### Build and Launch Containers
    ```bash
    docker compose up -d --build
    ```
  </Step>
</Steps>

## 2. Docker Services Overview

| Container Name | Image / Base | Internal Port | Host Port | Role |
| :--- | :--- | :--- | :--- | :--- |
| `emitmail-api` | Node 20 Alpine | `4000`, `2525` | `4000:4000`, `25:2525` | Express REST API & Inbound ESMTP server |
| `emitmail-worker` | Node 20 Alpine | — | — | BullMQ queue worker, DKIM signer & direct MX dispatcher |
| `emitmail-postgres` | PostgreSQL 16 Alpine | `5432` | `5432:5432` | Primary database (domains, mailboxes, messages, keys) |
| `emitmail-redis` | Redis 7 Alpine | `6379` | `6379:6379` | Distributed job broker & release cache |

## 3. Verifying Container Health & Diagnostic Logs

To inspect the real-time operational logs and Pre-Flight Deliverability diagnostics:

```bash
docker compose logs -f emitmail-api emitmail-worker
```

**Expected healthy output:**
```text
emitmail-api     | 🚀 EmitMail API server running on port 4000 (development)
emitmail-api     | 📬 [Inbound SMTP] Server listening on 0.0.0.0:2525 (EHLO: mail.yourdomain.com)
emitmail-worker  | ⚙️ [BullMQ Worker] Connected to Redis at emitmail-redis:6379
emitmail-worker  | 🔒 [Crypto] AES-256-GCM encryption verified for DKIM key storage
```

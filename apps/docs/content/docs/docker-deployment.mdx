## 1. Quickstart Commands

<Steps>
  <Step>
    ### Clone the Repository
    ```bash
    git clone https://github.com/omkarbhosale-dev/emitmail.git
    cd emitmail
    ```
  </Step>

  <Step>
    ### Create and Populate Environment File
    ```bash
    cp .env.example .env
    ```
  </Step>

  <Step>
    ### Configure Environment Variables
    Open `.env` in your preferred editor (`nano .env`) and update the key host settings:
    ```bash
    # Core Server Ports
    PORT=4000
    API_PORT=4000
    DASHBOARD_PORT=3000
    DOCS_PORT=3001

    # Public Web & Documentation Domains (Caddy Automated Reverse Proxy & SSL)
    DASHBOARD_DOMAIN=emitmail.yourdomain.com
    DOCS_DOMAIN=emitdocs.yourdomain.com
    # ACME email for automated Let's Encrypt TLS renewal notices
    ACME_EMAIL=admin@yourdomain.com

    # Security Keys
    # Must be at least 32 characters
    JWT_SECRET=emitmail_super_secret_jwt_key_change_in_prod_2026
    # 64-character hex string (32 bytes) for AES-256-GCM DKIM encryption
    ENCRYPTION_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef

    # Mail Server Network Configuration
    SMTP_EHLO_HOSTNAME=mail.yourdomain.com
    SENDING_SERVER_IP=198.51.100.1
    RETURN_PATH_SUBDOMAIN=send
    MAIL_SERVER_HOSTNAME=mail.yourdomain.com
    SPF_INCLUDE_DOMAIN=_spf.yourdomain.com
    VPS_PUBLIC_IPV4=198.51.100.1

    # Inbound SMTP Receiver Engine
    INBOUND_SMTP_ENABLED=true
    INBOUND_SMTP_PORT=2525
    INBOUND_SMTP_HOST=0.0.0.0
    INBOUND_MAX_BYTES=26214400
    ```
  </Step>

  <Step>
    ### Build and Launch Containers
    ```bash
    docker compose up -d --build
    ```
  </Step>
</Steps>

## 2. Docker Services Overview

| Container Name | Image / Base | Internal Port | Host Port | Role |
| :--- | :--- | :--- | :--- | :--- |
| `emitmail-caddy` | Caddy 2.9 Alpine | `80`, `443` | `80:80`, `443:443` | Automated TLS/SSL reverse-proxy for `emitmail` and `emitdocs` |
| `emitmail-dashboard` | Node 20 Alpine | `3000` | `3000:3000` | Management Web Dashboard & Analytics UI |
| `emitmail-docs` | Node 20 Alpine | `3001` | `3001:3001` | EmitDocs developer documentation platform |
| `emitmail-api` | Node 20 Alpine | `4000`, `2525` | `4000:4000`, `25:2525` | Express REST API & Inbound ESMTP server |
| `emitmail-worker` | Node 20 Alpine | — | — | BullMQ queue worker, DKIM signer & direct MX dispatcher |
| `emitmail-postgres` | PostgreSQL 16 Alpine | `5432` | `5432:5432` | Primary database (domains, mailboxes, messages, keys) |
| `emitmail-redis` | Redis 7 Alpine | `6379` | `6379:6379` | Distributed job broker & release cache |

## 3. Why `ACME_EMAIL` is Required

<Callout type="info" title="Automated Certificate Management Environment (ACME)">
**ACME** is the standardized protocol used by **Let's Encrypt** and ZeroSSL to issue and renew free TLS/SSL certificates automatically. 

Your `ACME_EMAIL` (`admin@yourdomain.com`) is used for:
1. **Critical Expiration Notices:** If an automated renewal ever encounters a DNS or network problem, Let's Encrypt alerts your administrator before certificates expire to prevent HTTPS downtime.
2. **Security & Key Revocation:** Alerts for any certificate authority maintenance or key emergency.
3. **CA Account Registration:** Creates the cryptographic signing identity for your server on Let's Encrypt's ledger.
</Callout>

## 4. Multi-Domain Ingress & Reverse Proxy Architecture

EmitMail routes external web, documentation, and mail traffic across 3 dedicated subdomains:

```text
https://emitmail.yourdomain.com  ──(Caddy :443)──► emitmail-dashboard:3000 & emitmail-api:4000
https://emitdocs.yourdomain.com  ──(Caddy :443)──► emitmail-docs:3001
smtp://mail.yourdomain.com       ──(Port 25)────► emitmail-api:2525 (MTA Dispatch & Inbound)
```

1. **Dashboard (`DASHBOARD_DOMAIN`):** Serves the Next.js console and handles `/api/*` and `/emails` (Resend compatibility layer) seamlessly on the same HTTPS origin.
2. **Docs (`DOCS_DOMAIN`):** Serves the Fumadocs developer documentation platform with isolated routing.
3. **Mail Hostname Fallback (`SMTP_EHLO_HOSTNAME`):** If a user visits `mail.yourdomain.com` in their web browser, Caddy automatically redirects them to the main dashboard.

## 1. What is EmitMail?

**EmitMail** is a self-hosted, Cloudflare-grade Email Service Provider (ESP) and Inbound Mailbox Engine. Built with Node.js, TypeScript, PostgreSQL, Redis, and BullMQ, EmitMail gives engineering teams complete control over their email deliverability, cryptographic keys, inbound routing, and operational privacy—without artificial per-email rate limits or monthly SaaS invoices.

```text
               ┌────────────────────────────────────────────────────────┐
               │                     EmitMail ESP                       │
               ├────────────────────────────┬───────────────────────────┤
               │       Outbound Engine      │       Inbound Engine      │
               ├────────────────────────────┼───────────────────────────┤
               │ • 2048-bit RSA DKIM Keys   │ • ESMTP Port 25 Receiver  │
               │ • Return-Path Alignment    │ • Alias & Catch-all Mail  │
               │ • BullMQ Worker Pipeline   │ • Real-time Webhooks      │
               │ • Resend SDK Drop-In       │ • In-Dashboard Reader/Sent│
               └────────────────────────────┴───────────────────────────┘
```

Migrate existing applications from Resend to EmitMail in under 60 seconds by changing only your `RESEND_BASE_URL` to point to your self-hosted instance. No code refactoring required.

## 2. Core Architecture & Processing Flow

EmitMail decouples API intake from SMTP network dispatch using Redis-backed distributed queues. This guarantees that your web applications receive immediate `<50ms` HTTP responses while background workers handle DNS MX resolution, cryptographic DKIM signing, and TLS socket connections.

### Outbound Dispatch Pipeline

```text
[ Client App / SDK ]
        │
        ▼ (POST /emails with Bearer em_live_...)
[ EmitMail Express API ] ──(Fast Validation <20ms)──► Return { id: "em_..." }
        │
        ▼ (Enqueue Job: email-delivery-queue)
[ Redis 7 + BullMQ ]
        │
        ▼ (Distributed Job Consumption)
[ EmitMail Worker Engine ]
        │
        ├─► [ PostgreSQL ] : Tenant suppression list check & domain verification
        ├─► [ Crypto Subsystem ] : Signs raw MIME payload with 2048-bit RSA DKIM private key
        ├─► [ DNS Resolver ] : Queries remote MX records for recipient domain
        ▼
[ Direct MX Dispatch ] ──(TLS 1.3 / Port 25)──► [ Receiving MTA: Gmail, Outlook, Yahoo ]
        │
        ▼ (Delivery or Bounce Event)
[ Webhook Dispatcher ] ──► [ Your Backend Server ]
```

### Inbound Ingestion Pipeline

```text
[ External Sender (e.g. Gmail) ]
        │
        ▼ (Port 25 TCP Connection)
[ Host Firewall: iptables REDIRECT 25 -> 2525 ]
        │
        ▼
[ EmitMail Inbound SMTP Server (smtp-server) ]
        │
        ├─► [ onRcptTo Hook ] : Validates active mailbox (exact alias or catch-all *)
        ▼
[ Redis Queue (inbound-email) ]
        │
        ▼
[ Inbound BullMQ Worker ]
        │
        ├─► [ mailparser ] : Parses MIME body, extracts HTML/text & attachments
        ├─► [ PostgreSQL ] : Stores thread in Inbox for dashboard viewing
        ▼
[ Webhook Dispatcher ] ──► HTTP POST webhook event (inbound.email.received)
```

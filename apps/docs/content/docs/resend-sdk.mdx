# Resend SDK Drop-in Guide

One of EmitMail's core design principles is **zero migration friction**. 

EmitMail provides a 100% compliant implementation of the Resend Email API specification. If your applications, SaaS platforms, or microservices are already written using the official `resend` library, you can redirect your email dispatch to your private EmitMail infrastructure without altering a single line of business logic.

---

## 1. Generate an API Key in EmitMail

Before sending emails, create an API key scoped to your verified domain:

1. Open your EmitMail Dashboard at `http://localhost:3000`.
2. Navigate to **API Keys** in the sidebar.
3. Click **+ Create API Key**.
4. Select your verified domain (e.g. `yourdomain.com`) and assign a descriptive label (e.g., `Production App - Backend Service`).
5. Copy your new secret key (formatted as `em_live_...`). Store it securely in your application's environment variables as `EMITMAIL_API_KEY`.

## 2. Node.js & TypeScript with Official Resend SDK

Install the official `resend` package from npm:

```bash
pnpm add resend
# or npm install resend / yarn add resend
```

### Sending an Email

Instantiate the `Resend` client by passing your EmitMail API key and setting `baseUrl` to your EmitMail instance's `/v1` endpoint:

```typescript
import { Resend } from 'resend';

// Initialize the official Resend client with your self-hosted EmitMail baseUrl
const resend = new Resend(process.env.EMITMAIL_API_KEY, {
  baseUrl: process.env.EMITMAIL_BASE_URL || 'http://localhost:4000/v1',
});

async function sendWelcomeEmail(recipientEmail: string, userName: string) {
  try {
    const { data, error } = await resend.emails.send({
      from: 'Acme Security <security@yourdomain.com>',
      to: [recipientEmail],
      subject: 'Welcome to Acme — Confirm Your Account',
      html: `
        <div style="font-family: sans-serif; max-width: 560px; margin: auto; padding: 24px; border: 1px solid #eaeaea; border-radius: 8px;">
          <h2 style="color: #111;">Welcome aboard, ${userName}!</h2>
          <p style="color: #444; line-height: 1.6;">
            Thank you for creating an account with Acme. Your email was dispatched securely through our sovereign EmitMail cluster.
          </p>
          <a href="https://yourdomain.com/verify" style="display: inline-block; background-color: #0066FF; color: #fff; padding: 12px 24px; text-decoration: none; border-radius: 6px; font-weight: 500; margin-top: 16px;">
            Verify Email Address
          </a>
        </div>
      `,
      reply_to: 'support@yourdomain.com',
      headers: {
        'X-Entity-Ref-ID': 'user-reg-9021',
      },
    });

    if (error) {
      console.error('Failed to dispatch email via EmitMail:', error);
      return { success: false, error };
    }

    console.log('Email queued successfully! EmitMail ID:', data?.id);
    return { success: true, id: data?.id };
  } catch (err) {
    console.error('Network or transport error:', err);
    throw err;
  }
}
```

## 3. Supported Features & Payloads

EmitMail accepts all standard Resend email parameters:

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `from` | `string` | Sender email address. Must belong to a verified domain in your EmitMail account. Supports `"Sender Name <user@domain.com>"` format. |
| `to` | `string[]` or `string` | One or multiple recipient email addresses. |
| `subject` | `string` | Email subject line. |
| `html` | `string` | HTML email body. |
| `text` | `string` (optional) | Plain text fallback. If omitted, EmitMail automatically parses HTML to text. |
| `cc` | `string[]` (optional) | Carbon copy recipients. |
| `bcc` | `string[]` (optional) | Blind carbon copy recipients. |
| `reply_to` | `string` (optional) | Reply-to destination email address. |
| `headers` | `Record<string, string>` | Custom MIME headers (e.g. `List-Unsubscribe`, `X-Entity-Ref-ID`). |
| `attachments` | `Array` (optional) | Binary or Base64 attachments with `filename` and `content`. |

### Sending with Attachments

```typescript
const { data, error } = await resend.emails.send({
  from: 'Billing <invoices@yourdomain.com>',
  to: ['client@example.com'],
  subject: 'Your Monthly Invoice #INV-2026-10',
  html: '<p>Please find attached your statement for October 2026.</p>',
  attachments: [
    {
      filename: 'invoice-1026.pdf',
      content: Buffer.from('%PDF-1.4 ...').toString('base64'),
    },
  ],
});
```

## 4. Python SDK Example

You can also use the official `resend-python` package:

```bash
pip install resend
```

```python
import os
import resend

# Configure the official Python SDK to route to EmitMail
resend.api_key = os.environ.get("EMITMAIL_API_KEY")
resend.api_url = "http://localhost:4000/v1"

params = {
    "from": "Acme Notifications <notifications@yourdomain.com>",
    "to": ["user@example.com"],
    "subject": "System Alert: Backup Completed",
    "html": "<strong>Your automated database backup completed successfully.</strong>",
}

email = resend.Emails.send(params)
print("Dispatched email ID:", email["id"])
```

## 5. Direct cURL / HTTP REST API

If you are calling the API from Go, Rust, Ruby, or shell scripts:

```bash
curl -X POST http://localhost:4000/v1/emails \
  -H "Authorization: Bearer em_live_your_secret_key" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Support <support@yourdomain.com>",
    "to": ["recipient@example.com"],
    "subject": "Direct REST Dispatch",
    "html": "<p>Sent via direct HTTP POST to EmitMail /v1/emails</p>"
  }'
```

### API Response
EmitMail returns a `<50ms` dual-compliant response:

```json

  "success": true,
  "data": {
    "id": "cm3b1c4e1000108l41b2c4d9a",
    "status": "QUEUED"
  }
}
```

## 6. Built-in Suppression Protection

When an email fails delivery due to a hard bounce or spam complaint, EmitMail adds the recipient to that domain's automatic **Suppression List**. 

If your application attempts to send an email to a suppressed address, EmitMail intercepts the request immediately in `<10ms` without consuming outbound bandwidth:

```json
{
  "id": "cm3b1c4e1000108l41b2c4d9b",
  "from": "Security <security@yourdomain.com>",
  "to": ["bounced-user@example.com"],
  "status": "suppressed",
  "message": "Email blocked by suppression list: Prior permanent hard bounce",
  "suppressed": true,
  "suppressionReason": "HARD_BOUNCE"
}
```
You can view, search, and release suppressed addresses anytime in the **Suppressions** tab of the EmitMail Dashboard.

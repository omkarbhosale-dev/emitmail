# Setting Up the Project

EmitMail is built as an extensible TypeScript monorepo managed with `pnpm`. You can run EmitMail in production using **Docker Compose** or run it locally for customization and testing.

---

## 1. System Requirements

Ensure your host or VPS satisfies the following requirements:
- **Operating System**: Linux (Ubuntu 22.04+ / Debian 12 recommended) or macOS / Windows with WSL2
- **Docker**: Engine version 24.0+ and Docker Compose v2.20+
- **Node.js**: v20.10.0+ LTS
- **Package Manager**: `pnpm` v9.0+ (`corepack enable pnpm`)

---

## 2. Clone the Repository

Clone the EmitMail repository from GitHub:

```bash
git clone https://github.com/omkarbhosale-dev/emitmail.git
cd emitmail
```

---

## 3. Environment Configuration

Copy the example environment configuration into your `.env` file:

```bash
cp .env.example .env
```

### Environment Variables Breakdown

Edit `.env` to configure your database, cache, secrets, and server ports:

```bash
# ─── CORE DATABASE & REDIS ───────────────────────────────────
DATABASE_URL="postgresql://emitmail:emitmail_secret_pass@localhost:5432/emitmail?schema=public"
REDIS_URL="redis://localhost:6379"

# ─── APPLICATION SECURITY & AUTH ─────────────────────────────
# Generate a 32-character secret with: openssl rand -base64 32
JWT_SECRET="your-super-secret-jwt-token-key-minimum-32-chars"
# AES-256 64-char hex key for DKIM private key encryption: openssl rand -hex 32
ENCRYPTION_KEY="0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"

# ─── SUPER ADMIN CREDENTIALS ─────────────────────────────────
ADMIN_USERNAME="admin"
ADMIN_DEFAULT_PASSWORD="emitmail"

# ─── SERVICE PORTS & URLS ────────────────────────────────────
PORT=4000
API_URL="http://localhost:4000"
NEXT_PUBLIC_API_URL="http://localhost:4000"
DASHBOARD_PORT=3000

# ─── SMTP INFRASTRUCTURE ─────────────────────────────────────
SMTP_HOSTNAME="mail.yourdomain.com"
SMTP_PORT=25
SMTP_SUBMISSION_PORT=587
SMTP_TLS_PORT=465
```

## 4. Production Deployment with Docker Compose

The fastest way to deploy EmitMail in production is with Docker Compose. The stack orchestrates PostgreSQL 16, Redis 7, the REST API, BullMQ background dispatch workers, and the Next.js Dashboard.

### Start the Services

```bash
# Build and run all containers in the background
docker compose up -d --build
```

### Run Migrations & Database Seed

Once the database container is healthy, run the Prisma schema migrations and populate initial system settings:

```bash
# Run database migrations
docker compose exec api pnpm --filter @emitmail/database prisma migrate deploy

# Seed the root super-admin account and initial configurations
docker compose exec api pnpm --filter @emitmail/database prisma db seed
```

### Inspect Container Status & Logs

```bash
# Check running containers
docker compose ps

# Follow logs from the email dispatch worker
docker compose logs -f worker

# Follow API request logs
docker compose logs -f api
```

## 5. Local Development Workflow

If you want to contribute to EmitMail or test changes locally without Docker:

### 1. Install Dependencies
```bash
pnpm install
```

### 2. Start PostgreSQL & Redis
You can launch local PostgreSQL and Redis instances using Docker:
```bash
docker compose up -d postgres redis
```

### 3. Apply Schema & Seed Database
```bash
pnpm --filter @emitmail/database prisma db push
pnpm --filter @emitmail/database prisma db seed
```

### 4. Start Monorepo Dev Servers
Run the API, Dashboard, and Documentation concurrently:
```bash
pnpm dev
```

The services will be available at:
- **Dashboard**: `http://localhost:3000`
- **Documentation**: `http://localhost:3001`
- **API Engine**: `http://localhost:4000`
- **API Health Check**: `http://localhost:4000/health`

## 6. First Login & Initial Setup

1. Open `http://localhost:3000` in your browser.
2. Sign in with the primary administrator credentials:
   - **Username**: `admin`
   - **Password**: `emitmail`
3. Navigate to **Settings** (`/settings`):
   - Change your default admin password immediately.
   - Invite your team members under the **Team** tab with assigned roles (`ADMIN`, `MEMBER`, or `VIEWER`). EmitMail automatically generates personalized SVG identity hashes for each member using `facehash`.
4. Head to **Domains** to connect your sending domain.
